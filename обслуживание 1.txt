# Обслуживание проекта через bat-скрипты

Набор `.bat`-скриптов предназначен для создания, активации, пересоздания и использования виртуального окружения проекта, а также для запуска сканирования в этом окружении.

Скрипты рассчитаны на Windows и используют виртуальное окружение `agentsenv`.

---

## Краткая схема работы

Обычный порядок использования:

```bat
venv0.1.bat
venv0.2.bat
venv0.4.bat
```

Если окружение нужно пересоздать с нуля:

```bat
venv0.3.bat
venv0.2.bat
venv0.4.bat
```

---

## Назначение скриптов

### `venv0.1.bat`

Первичное создание виртуального окружения.

Что делает:

1. Проверяет наличие Python по пути:

   ```bat
   C:\Users\Hatul\AppData\Local\Programs\Python\Python312\python.exe
   ```

2. Создаёт виртуальное окружение в папке:

   ```bat
   agentsenv
   ```

3. Активирует созданное окружение.

Использовать, если окружение ещё не создано.

---

### `venv0.2.bat`

Активация окружения и обновление зависимостей.

Что делает:

1. Проверяет наличие окружения:

   ```bat
   agentsenv\Scripts\activate.bat
   ```

2. Активирует виртуальное окружение.

3. Устанавливает:

   ```bat
   pytest
   pytest-cov
   ```

4. Обновляет файл зависимостей:

   ```bat
   requirements.txt
   ```

Использовать после установки новых пакетов или для актуализации `requirements.txt`.

---

### `venv0.3.bat`

Полное пересоздание виртуального окружения.

Что делает:

1. Проверяет наличие Python.
2. Удаляет старое окружение `agentsenv`, если оно существует.
3. Создаёт новое виртуальное окружение.
4. Активирует его.

Использовать при проблемах с окружением, конфликтах зависимостей или для чистой установки.

---

### `venv0.4.bat`

Запуск рабочего скрипта в виртуальном окружении.

Что делает:

1. Проверяет наличие окружения.
2. Активирует виртуальное окружение.
3. Запускает:

   ```bat
   python scan_tree.py
   ```

4. Сообщает результат выполнения по коду возврата.

Использовать для запуска сканирования проекта.



## Возможные проблемы

### Ошибка: `Виртуальное окружение не найдено`

Окружение ещё не создано или папка `agentsenv` удалена.

Решение:

```bat
venv0.1.bat
```

или:

```bat
venv0.3.bat
```

---

### Ошибка: `Python не найден по пути`

Неверный путь к `python.exe`.

Откройте `venv0.1.bat` и `venv0.3.bat`, затем исправьте строку:

```bat
set PYTHON_PATH=C:\Users\Hatul\AppData\Local\Programs\Python\Python312\python.exe
```

---

### Ошибка: `Не удалось полностью удалить старое окружение`

Папка `agentsenv` используется другим процессом.

Решение:

1. Закройте все терминалы и IDE, где может быть активно окружение.
2. Завершите процессы `python.exe`, если они остались.
3. Повторно запустите:

   ```bat
   venv0.3.bat
   ```
