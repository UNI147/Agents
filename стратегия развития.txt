ВЕКТОР 1 — Углубление эволюционной динамики

1.1 Расширить набор стратегий: TFT, WSLS, Generous TFT, Always-D, Always-C
1.2 Повторные взаимодействия + память: агент запоминает последних партнёров
1.3 Правила имитации (Fermi rule, proportional imitation): агент может сменить стратегию, копируя более успешного соседа
1.4 Moran / Wright–Fisher процесс для конечных популяций
1.5 Репликаторное уравнение как аналитический бенчмарк: сравнивать агентную динамику с ODE ẋ = x(f_C − f̄)
1.6 Многоуровневый отбор (group selection): разбить популяцию на группы, конкуренция групп

ВЕКТОР 2 — Усложнение среды и пространства

2.1 Несколько типов ресурсов (sugar + spice) и обмен
2.2 Загрязнение / истощение: потребление оставляет «отходы», снижающие capacity
2.3 Миграция между «островами»: несколько сред, агенты могут перемещаться
2.4 Болезни / паразиты: заражение при контакте, влияет на метаболизм
2.5 Пространственная неоднородность с динамикой: пики ресурсов дрейфуют, появляются/исчезают

ВЕКТОР 3 — Социальная структура и взаимодействие

3.1 Граф социальных связей (networkx): агенты играют не со случайными, а с соседями по сети
3.2 Репутация и непрямой реципрокитет: агент имеет score, видимый другим
3.3 Коалиции / альянсы: группы агентов совместно обороняют ресурс
3.4 Коммуникация: агенты обмениваются сигналами (cheap talk)
3.5 Институты / правила: «налог» на дефекторов, «суд» — принудительные механизмы

ВЕКТОР 4 — Обучение и адаптация агентов

4.1 Обучение с подкреплением (Q-learning): агент учится, где собирать ресурс
4.2 Эволюция скорости обучения: геном кодирует learning rate
4.3 Fictitious play / best response dynamics: агент строит модель оппонента
4.4 Культурная передача: агент копирует стратегию соседа без генетического наследования

ВЕКТОР 5 — Инфраструктура и инженерия

5.1 Переход на Mesa или создание аналогичной архитектуры (Model / Agent / Space / Scheduler)
5.2 Batch runner: параметрический свип (mutation_rate × season_period × T/R ratio) с multiprocessing
5.3 Интерактивная визуализация в браузере (Solara / Jupyter widgets)
5.4 Экспорт данных в CSV/Parquet + статистический анализ (bootstrap CI для частоты C)
5.5 Тесты и верификация: unit-тесты на payoff, conserve resource, deterministic seed
5.6 Конфигурация через YAML/TOML вместо dataclass-хардкода
5.7 Docker / reproducibility: фиксация версий, seed в metadata

ВЕКТОР 6 — Аналитика и визуализация

6.1 Фазовые диаграммы в координатах (T−R, b/c) — границы фиксации C/D 
6.3 Распределение ресурсов (гистограмма, Gini coefficient) — неравенство
6.4 Кластеризация агентов по геному (PCA / UMAP)
6.5 Сравнение с ODE: на одном графике agent-based vs replicator equation
